Todo projeto de automação residencial deste site — sensor de vazamento, monitor de consumo elétrico, controle de portão — começa com uma placa maker na mão. Comparamos 3 kits iniciantes vendidos no Brasil para ajudar a escolher o primeiro (ou o próximo) kit, e explicamos por que a escolha entre Arduino e ESP32 importa mais do que parece.

## Como avaliamos

- **Tipo de placa** — Arduino Uno (sem conectividade nativa) ou ESP32 (Wi-Fi + Bluetooth integrados).
- **O que vem no kit** — sensores, protoboard, componentes e material de apoio (manual/projetos).
- **Facilidade para o primeiro projeto** — quão rápido dá para sair do zero e ver algo funcionando.
- **Validação real** — nota e volume de avaliações de quem já comprou.

## Arduino ou ESP32: a decisão que mais importa

Antes de escolher o kit, entenda a diferença real entre as placas. O **Arduino Uno** é o clássico — simples, com a maior comunidade e tutorial do mundo maker, mas **sem Wi-Fi ou Bluetooth de fábrica**. Ótimo para aprender lógica de programação e eletrônica básica (acender LED, ler botão, mover servo).

O **ESP32** já nasce com Wi-Fi e Bluetooth integrados, além de processador dual-core mais potente. É a placa por trás de praticamente todos os tutoriais de automação residencial deste site — sensor de vazamento de água, monitor de consumo elétrico, controle de portão via Home Assistant — justamente porque ela conversa direto com a rede Wi-Fi de casa, sem módulo adicional.

**Se seu objetivo final é automação residencial de verdade, comece direto no ESP32.** Se é aprender programação/eletrônica do zero sem pressa para chegar na automação, o Arduino Uno também é um ótimo ponto de partida.

## Perguntas frequentes

**Arduino ou ESP32 para começar?**
Se o objetivo é automação residencial, ESP32 (Wi-Fi/Bluetooth nativo). Se é aprender do zero sem pressa, Arduino Uno também serve bem.

**Dá para fazer os tutoriais do site com Arduino Uno?**
Não diretamente — falta Wi-Fi nativo. ESP32 poupa esse passo extra.

**Preciso saber programar?**
Não para começar — os kits vêm com projetos prontos para carregar e adaptar aos poucos.

**O que vem nesses kits?**
Placa, protoboard, jumpers, LEDs, resistores, botões, buzzer e sensores básicos (temperatura, distância, luz).

**Vale comprar peça avulsa em vez de kit?**
Só se você já sabe exatamente o que vai construir. Para quem está começando, o kit compensa.
