Instalar o Home Assistant num Raspberry Pi é mais simples do que a fama sugere. O sistema tem uma imagem pronta, o gravador oficial já traz ela na lista, e o processo inteiro é gravar um cartão e ligar a placa.

O que dá errado quase nunca é a instalação. É o hardware. Fonte que não entrega corrente, cartão de memória inadequado e falta de refrigeração respondem pela maioria dos "meu Home Assistant reinicia sozinho" que aparecem em fórum — e todos os três são problemas invisíveis, que se manifestam como instabilidade aleatória semanas depois.

Este guia cobre as duas partes: o hardware que funciona de verdade, com os requisitos que a documentação oficial estabelece, e o passo a passo da instalação até o primeiro acesso.

## O hardware, com os requisitos oficiais

A documentação do Home Assistant é específica sobre o que é necessário:

| Item | Requisito oficial |
|---|---|
| Placa | Raspberry Pi 5 com **fonte adequada** — a documentação avisa para **não usar carregador de celular** |
| Cartão | **Mínimo 32 GB**, idealmente com classificação **Application Class 2** (rótulo A2) |
| Leitor de cartão | Integrado ao notebook ou adaptador USB |
| Rede | **Cabo Ethernet obrigatório** para a instalação (Wi-Fi pode ser configurado depois) |

Vale destrinchar os dois requisitos que mais são ignorados.

**A fonte.** O Pi 5 pede USB-C de 27 W com negociação PD correta. Carregador de celular comum não entrega essa corrente sob carga. O sintoma é traiçoeiro: a placa liga normalmente, funciona bem enquanto está ociosa e reinicia quando o processador exige mais — durante uma atualização, ao iniciar um add-on pesado. Você passa dias achando que é problema de software.

**O cartão A2.** A classificação A2 não é sobre velocidade de transferência de arquivo grande, é sobre **operações pequenas e aleatórias por segundo**. Isso é exatamente o padrão de uso de um sistema operacional, e mais ainda de um Home Assistant gravando estado de sensor a cada poucos segundos. Cartão de câmera, mesmo com número grande de MB/s estampado, se sai mal nesse teste.

## Passo 1: gravar o cartão

O Raspberry Pi Imager já traz a imagem do Home Assistant, então você não precisa baixar nada por fora.

1. Baixe e instale o **Raspberry Pi Imager** em `raspberrypi.com/software`.
2. Abra o programa e clique em **OS** (escolher sistema operacional).
3. Navegue até **Other specific-purpose OS → Home automation → Home Assistant**.
4. Escolha a imagem do **Home Assistant OS correspondente ao seu hardware** — no caso, RPi 5.
5. Insira o cartão no leitor e selecione ele como **Storage**.
6. Clique em **Next** e depois em **Write**.
7. Aguarde a gravação e a verificação, clique em **Finish** e ejete o cartão.

Duas observações que economizam tempo:

**Não use as personalizações do Imager.** O gravador oferece configurar usuário, Wi-Fi e SSH antes de gravar — isso é para o Raspberry Pi OS, não para o Home Assistant OS, que tem o próprio fluxo de configuração. Deixe tudo em branco.

**Confira que escolheu a imagem do Pi 5.** A lista tem imagens para várias gerações de placa, e gravar a de outro modelo resulta em placa que não dá vídeo nem sobe na rede — falha que parece hardware queimado e não é.

## Passo 2: primeiro boot

1. Insira o cartão gravado no Raspberry Pi.
2. Conecte o **cabo Ethernet** no roteador.
3. Conecte a fonte por último.

A placa vai iniciar e começar a preparar o sistema. Esse primeiro boot demora mais que os seguintes, porque ele expande o sistema de arquivos e baixa componentes.

Não desligue no meio, mesmo que pareça travado. Interromper o primeiro boot é a forma mais fácil de corromper a instalação e ter que gravar tudo de novo.

## Passo 3: primeiro acesso

Depois de cerca de um minuto no Pi 5, abra o navegador em:

```
homeassistant.local
```

Se o nome não resolver — alguns roteadores não fazem resolução mDNS —, tente:

```
homeassistant.local:8123
```

E se ainda assim não abrir, entre na lista de dispositivos conectados do seu roteador, encontre o IP que a placa recebeu e acesse:

```
http://<IP-DA-PLACA>:8123
```

A tela de boas-vindas pede para criar o usuário administrador. Escolha uma senha real: esse painel vai controlar fechadura, câmera e tudo que você automatizar depois.

Em seguida ele pede nome da casa, localização, fuso e sistema de unidades. A localização importa mais do que parece — várias automações dependem de nascer e pôr do sol calculados a partir dela.

## Passo 4: os ajustes que evitam problema depois

Com o sistema no ar, três coisas que eu faço antes de qualquer automação.

**Fixe o IP da placa.** No seu roteador, reserve o IP por endereço MAC. Home Assistant que muda de IP quebra integração, atalho salvo e qualquer coisa apontando para o endereço antigo.

**Configure backup automático.** Em Configurações, Sistema, Backups. Backup que mora só no cartão não protege contra a falha mais provável, que é o próprio cartão corromper. Aponte para um destino externo.

**Ative a atualização, mas não automática.** Home Assistant tem ciclo de release rápido, e atualização pode quebrar integração. Prefira atualizar quando você tiver tempo de reverter, não às três da manhã sozinho.

## Perguntas frequentes

**Preciso mesmo de cabo de rede para instalar?**
Para a instalação, sim. A documentação oficial lista o cabo Ethernet como requisito: o Home Assistant OS sobe sem Wi-Fi configurado e precisa de rede para completar a primeira etapa. Depois você configura o Wi-Fi pela interface, mas para servidor eu deixaria no cabo.

**Qual cartão de memória usar?**
No mínimo 32 GB e, idealmente, com classificação Application Class 2 — o rótulo A2. Essa classificação existe para uso como disco de sistema, com muita operação pequena e aleatória, que é o padrão do Home Assistant.

**Posso usar carregador de celular no Raspberry Pi 5?**
Não. A documentação avisa explicitamente para não usar. O Pi 5 pede fonte USB-C de 27 W com negociação PD correta. O sintoma da fonte fraca é cruel: funciona parado e reinicia sob carga.

**Qual endereço acesso depois de ligar?**
`homeassistant.local`, disponível em cerca de um minuto no Pi 5. Se o roteador não resolver o nome, use `homeassistant.local:8123` ou o IP da placa com `:8123` no final.

**Vale a pena trocar o cartão SD por SSD?**
Vale, se o uso for para durar. O banco do Home Assistant escreve o tempo todo e cartão SD tem ciclos finitos. SSD elimina a falha mais chata que existe: corrupção silenciosa que só aparece quando você precisa do backup.

## Veredicto

A instalação em si leva vinte minutos e o Raspberry Pi Imager faz o trabalho pesado. Se você seguir os quatro passos acima, vai estar com o Home Assistant no ar hoje.

O que vale o seu cuidado é o hardware, e nele existe uma hierarquia clara de importância: **fonte de 27 W é inegociável**, cartão A2 é fortemente recomendado e refrigeração ativa evita o problema mais silencioso dos três. Economizar em qualquer um deles não dá erro na hora — dá instabilidade semanas depois, quando você já esqueceu o que comprou e vai culpar o software.

E antes de automatizar qualquer coisa: **fixe o IP e configure backup externo**. As duas coisas levam cinco minutos e são o que separa um susto de uma tarde inteira reconstruindo a casa do zero.
