## Confira que o anúncio é a versão Express

Veja o formato, a capacidade, o código e o vendedor. Procure a identificação **microSD EX** que aparece no material da Nintendo. Se as fotos de cores ou capacidades diferentes usam o mesmo título, abra a opção exata antes de comparar. Um microSD comum pode ter classe U3 ou A2 e ainda ser de um padrão diferente.

No primeiro uso, a Nintendo informa que é necessária uma atualização do sistema pela internet. Faça isso num momento em que você possa deixar o download terminar. Se trocar de cartão depois, siga o [processo oficial de transferência entre cartões Express](https://pt-americas-support.nintendo.com/app/answers/detail/a_id/70034/). Para um uso em que a soma de jogos se mantém bem abaixo do limite, 256 GB poupa orçamento. Se a lista de títulos ocupa espaço perto dele em quase todo mês, 512 GB compra principalmente conveniência.

Quando o número importa para chegar perto de um limite, use os dados do console como referência e inclua uma folga para o que falta baixar.

Há mais de um tipo de mídia física. Um cartão de jogo pode trazer software no próprio cartão e ainda receber atualizações baixadas. Dados salvos têm outra função. A [Nintendo informa que o progresso fica na memória do sistema](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68218/c/947). Para proteger progresso numa mudança de console, consulte separadamente as opções da conta e do título. Tire uma captura das telas de ocupação antes de reorganizar. Observe se parte considerável vem de vídeos, de grandes jogos ou de muitos títulos pequenos. Decide-se primeiro o gargalo real. Se o problema vem de capturas que você quer guardar, pesquise no menu a forma prevista de copiar e organizar. Se a necessidade vem de um grupo de jogos grandes que você pretende manter, use o tamanho real dessas instalações para escolher o cartão.

Na primeira utilização, siga a atualização via internet prevista. Depois confira se o cartão aparece no gerenciamento de dados e se a capacidade combinou com a variante selecionada. Antes de mover uma biblioteca inteira, use o fluxo oficial para instalar ou mover um título pequeno e valide o funcionamento.

Um cartão que servia no Switch anterior pode ser compatível com importação de mídia e ainda ter a especificação errada para expansão no Switch 2. ### Muitos jogos em mídia física de tipos diferentes
